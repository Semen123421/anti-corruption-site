# 🛡️ СтопКоррупция

Одностраничный сайт о борьбе с коррупцией: статистика, интерактивная heat-карта горячих точек (CPI 2025), советы и форма обратной связи.

## ✨ Фишки
- Анимированный фон с частицами, реагирующий на мышь
- Glitch-эффект заголовка
- Счётчики, запускающиеся при скролле
- 3D-tilt карточки
- Интерактивная heat-карта коррупции (Leaflet + Leaflet.heat)
- Полная адаптивность

## 🛠️ Технологии
- HTML5, CSS3, Vanilla JS
- Leaflet 1.9.4 + Leaflet.heat
- Google Fonts (Manrope)
